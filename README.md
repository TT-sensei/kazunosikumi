# number-park（すうじパーク）

小学校2〜3年生向けの、数の構成・分解や大きな数（〜1億）のしくみを、操作しながら学ぶWebアプリです。

**公開ページ：** https://tt-sensei.github.io/kazunosikumi/

HTML / CSS / JavaScript（Vanilla）で構成した静的Webアプリです。ビルド工程やバックエンドを必要とせず、GitHub Pagesなどの静的ホスティングで動作します。

## 教育的なねらい

「操作 → 気づき → 言語化」の流れを大切にしています。子どもが数を動かしたり、まとまりを変えたり、数どうしを比べたりしながら、変化に気づき、結果を算数の言葉で説明できることを目指します。

画面は、タブレットでの利用を想定し、学習メニューを「チャレンジ」「数のしくみを調べる」「学習の記録」に整理しています。狭い画面でも操作しやすいようにレイアウトを調整し、選択中のメニューが分かる状態表示や、キーボード操作時のフォーカス表示にも配慮しています。

## 学習できること

- **チャレンジ**：問題タイプを選び、ランダムに出題される10問に取り組みます。正誤判定やヒントを使いながら、学んだことを確かめます。
- **数をつくる（構成）**：`+100` / `+10` / `+1` などの操作で数をつくり、「100が3こ、10が2こ」のように位ごとのまとまりを確かめます。表示できるまとまりは、設定に応じて広げられます。
- **シュシュっとかず作り**：1・10・100・1000などのまとまりを使い、目標の数をつくります。ぴったりモードやお宝モード、投げた数の記録、1手戻す操作、位ごとの分解表示があります。
- **数を分ける（分解）**：入力した数を位ごとのまとまりに分けて確認します。
- **数のならび（数直線）**：とび数を選び、数直線上で何回進むとどの数に着くかを調べます。
- **大きさくらべ**：2つの数を位ごとに比べ、大小関係や差を確かめます。
- **いくつ分（単位）**：選んだ単位が何こ分あるか、あまりがあるかを調べます。
- **ナビキャラ**：6人のキャラクターが、問題選択やヒント、正解、やり直し、チャレンジ完了などを案内します。
- **バッジコレクション**：正解数や問題への挑戦、セット完了などの条件に応じてバッジを集めます。
- **ふりがな**：対応する案内文のルビを切り替えられます。設定は利用している端末に保存されます。クイズの問題文や入力パッドにはふりがなを付けません。

## 画面・操作の設計方針

- タブレットでの操作を重視し、タップしやすい入力欄やボタンを目指します。
- 画面幅に合わせて入力欄や結果カードを並べ替え、必要な場合は数直線・比較表を横に動かして確認できるようにします。
- 学習メニューの選択状態を見た目とアクセシビリティ属性の両方で伝えます。
- 学習内容や問題データを保ったまま、画面の見やすさと操作性を改善します。

## 技術・動作環境

- HTML / CSS / JavaScript（Vanilla）
- ES Modulesを使用
- データ保存には、各機能で実装されているブラウザ内の保存機能を使用します。
- 外部API、サーバーサイド処理、ビルド工程は不要です。
- 正解音は音声ファイルを読み込まず、クイズ機能内でWeb Audio APIにより生成します。
- シュシュっとかず作りは、外部音声を使わずCSSの演出で動きを表現します。

## 起動方法

公開ページを開くか、リポジトリを取得して `index.html` をブラウザで開きます。ES Modulesを利用しているため、ローカルで直接開いて動作しない場合は、リポジトリのルートで簡易HTTPサーバーを起動してください。

```bash
python3 -m http.server 8000
```

ブラウザで http://localhost:8000 を開きます。

## 問題データの追加・編集

問題データは `modules/problemSets.js` にあります。問題の追加や修正をするときは、既存のデータ構造と問題タイプを確認し、正解だけでなく、子どもが誤解しやすい表現やヒントの分かりやすさも確かめてください。

主な問題タイプ：

| タイプ | 内容 |
| --- | --- |
| `読み書き・位取り` | 漢数字と数字の変換、0を含む位取り |
| `構成・相対的な大きさ` | 「〇を△こ」の読み取り、まとまりの変換 |
| `10倍・100倍・1/10` | 位の移動、万・億をまたぐ変化 |
| `数直線・前後・大小比較` | 目盛り、前後の数、不等号 |
| `思考力・カード問題` | 0を含む最大・最小、条件に合う数 |

## 変更時の確認ポイント

- 学習メニューがすべて切り替わること
- 各機能の入力欄・ボタンがタブレットやスマートフォンで操作できること
- 数直線・位取り表・結果カードが画面からはみ出したり、文字がつぶれたりしないこと
- チャレンジの出題、正誤判定、ヒント、バッジ、ふりがな切替が従来どおり動作すること
- ふりがな設定などの端末内保存が維持されること
- ブラウザのコンソールにエラーが出ないこと

UIの変更では、学習ロジックや問題データを必要なく変更しないようにし、機能ごとに差分を分けて確認します。

## サウンド

外部の音声ファイルは使用しません。クイズの正解音はWeb Audio APIで生成し、シュシュっとかず作りはCSSの動きで表現しています。

# number-park（すうじパーク）

小学校2〜3年生向けに、大きな数（〜1億）のしくみを直感的に理解するためのWebアプリです。
HTML / CSS / JavaScript（Vanilla）だけで作られているため、ビルドなしでGitHub Pagesに配置できます。

## 教育的ねらい

すべての機能は「操作 → 気づき → 言語化」の流れを大切にしています。
児童がボタンやスライダーを操作し、数の変化に気づき、結果表示の文章を読んで算数の言葉で説明できることを目指します。

扱う内容は、位取り、数の構成と分解、数の大小比較、とび数、単位あたりの個数、数の仕組みです。

## 各機能

- **数をつくる（構成）**: `+100` / `+10` / `+1` ボタンで数を作り、「100が3こ、10が2こ、1が0こ」のように表示します。
- **数を分ける（分解）**: 入力した数を、100・10・1のまとまりに分けて表示します。
- **数のならび（数直線）**: スライダーと、とび数（1 / 2 / 5 / 10 / 50 / 100）で数直線上のジャンプを確認します。
- **大きさくらべ**: 2つの数を比較し、「○○は△△より□□大きい」と差分を言語化します。
- **いくつ分（単位）**: 「1000が290こで290000」のように、選んだ単位が何こ分あるかを調べます。割り切れない場合はヒントを表示します。
- **チャレンジ**: 外部化した問題データからランダムに出題し、正誤判定、ヒント表示、Web Audio APIによる正解音を行います。

## 使い方

`index.html` をブラウザで開くだけで動作します。
ローカルサーバーで確認する場合は、次のように実行できます。

```bash
python3 -m http.server 8000
```

その後、ブラウザで `http://localhost:8000` を開きます。

## 問題追加方法

問題は `modules/problemSets.js` にまとめています。
現在は固定配列ではなく、レベルごとに毎回ランダムな20問を生成します。5類型から最低3問ずつ出し、0を含む数、9999→10000の境界、1000万−1万、位のずれ、カード問題を意図的に含めます。

対応タイプは次のとおりです。

| type | 内容 |
| --- | --- |
| `読み書き・位取り` | 漢数字⇄数字、0を含む位取り |
| `構成・相対的な大きさ` | 「〇を△こ」と逆パターン、まとまりの変換 |
| `10倍・100倍・1/10` | 位の移動、万・億をまたぐ変化 |
| `数直線・前後・大小比較` | 目盛りを考える数直線、前後の数、不等号 |
| `思考力・カード問題` | 0を含む最大・最小・条件付き問題 |

## サウンド

音声ファイルは使いません。正解音は `modules/quizEngine.js` の Web Audio API で生成しています。
